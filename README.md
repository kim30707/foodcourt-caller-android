# 호출 방송 (foodcourt-caller-android)

푸드코트 매장 태블릿의 숫자 키패드에서 `-` 번호 `Enter`를 치면, 앰프 옆 방송 폰이
"(딩동) 하즈벤 24번 고객님, 주문하신 음식이 나왔습니다."를 방송하는 안드로이드 앱입니다.

- 기존 호출 시스템(호출 앱, 호출 서버, 모니터 셋톱, 포스기)은 건드리지 않습니다. 태블릿에는 이 앱만 추가합니다.
- 인터넷 없이 건물 안 와이파이로만 통신합니다. 인터넷이나 호출 서버가 멈춰도 와이파이만 살아 있으면 방송됩니다.
- 설치 파일(APK)은 두 가지입니다.
  - `foodcourt-caller.apk`: 매장 태블릿용. 처음 실행할 때 **매장용**(또는 방송용)을 고릅니다. 키패드를 가로채는 접근성 기능이 들어 있습니다.
  - `foodcourt-caller-speaker.apk`: **방송 전용**(앱 이름 "호출 방송(방송용)"). 접근성 기능이 없어 설치가 쉽고, 열면 바로 방송용 화면입니다. 방송 태블릿·폰에는 이것을 설치합니다.
- 방송용 화면의 **음악 자동 켜기/끄기**로 영업 시작·종료 시각에 같은 기기의 음악 앱(유튜브 뮤직 등)을 재생·정지할 수 있습니다.

```
[숫자 키패드] → [매장 태블릿: 매장용 앱] ──건물 와이파이──→ [방송 폰: 방송용 앱] → [앰프] → [스피커]
                     └ '-' 없이 친 번호 + Enter는 기존 호출 앱으로 그대로 전달
[직원 휴대폰 웹페이지] ──예비 입구──→ [방송 폰: 방송용 앱]
```

## 그림 설치 안내서

<https://kim30707.github.io/foodcourt-caller-android/> — 로그인 없이 휴대폰으로 볼 수 있습니다(키패드 연습판, 단계별 화면 그림, 설치 QR).
원본은 `docs/index.html`이며, 고쳐서 main에 올리면 1~2분 뒤 같은 주소에 반영됩니다.

## 키패드 사용법(매장 직원)

| 누르는 키 | 결과 |
|---|---|
| `2` `4` `Enter` | 지금처럼 호출 화면에만 뜸(방송 안 함) |
| `-` `2` `4` `Enter` | 호출 화면에는 안 뜨고 방송: "24번 고객님…" |
| `-` `2` `Backspace` `3` `Enter` | 23번 방송 |
| `-` 누르고 8초 가만히 | 취소 |
| `-` `Enter` | 취소 |

화면 위쪽에 작은 배너가 뜹니다: `방송 번호: 24_` → `24번 방송 요청 완료` (실패하면 빨간 `방송 장치에 연결 안 됨`).

## 5. 설치 순서

메뉴 이름은 삼성 갤럭시 기준이다. 버전마다 위치가 다른 메뉴는 설정 화면 위쪽 돋보기(검색)에 이름을 넣어 찾는다.

### 5-1. 방송 폰

> **운영 결정(2026-11-13): 지금 앰프에 블루투스로 음악을 트는 폰을 방송 폰으로 같이 쓴다.**
> 음악은 그대로 나오고, 방송하는 동안만 음악 소리가 줄었다가 돌아온다(오디오 포커스 덕킹, 같은 폰이라 동작함).
> 이 폰은 2층 장비실에 두고 충전기에 꽂아 두며, 와이파이를 켜 둔다(모바일 데이터만으로는 태블릿이 찾지 못함).
> 개인 폰이면 퇴근 때 가져가지 않도록 한다. 앰프 블루투스 연결은 지금 그대로 쓰므로 6번은 확인만 한다.

1. 화면 잠금 없애기: 설정 → 돋보기 → "화면 잠금 방식" 검색 → [화면 잠금 방식] → 지금 비밀번호 입력 → [없음]. 잠금이 없어야 폰이 다시 켜졌을 때 서버가 저절로 켜진다.
2. 와이파이 연결: 설정 → [연결] → [Wi-Fi] → 2층 와이파이 선택. 이름이 두 개면 5G가 붙지 않은 쪽(2.4GHz)을 고른다.
3. 앱 설치: Chrome에서 고정 주소 열기 → [다운로드] → 아래 알림에서 [열기] → "설치할 수 없도록 설정되어 있습니다" 창에서 [설정] → [이 출처 허용] 켜기 → 뒤로 → [설치].
   - Play 프로텍트 경고가 뜨면 [자세히]를 눌러 설치를 계속하는 버튼을 누른다. 버튼 문구는 버전마다 조금 다르다.
   - "자동 차단" 때문에 설치가 막히면: 설정 → 돋보기 → "자동 차단" 검색 → 끄기. 설치가 끝나면 다시 켜도 된다.
4. 앱 첫 설정: 앱 실행 → [방송용] → 알림 [허용] → 앱의 [배터리 제한 없음으로] → [허용].
5. 배터리 보호: 설정 → 돋보기 → "배터리 보호" 검색 → 켜기. 선택지가 있으면 [최대]를 고른다. 늘 충전기에 꽂아 두어도 배터리가 덜 부푼다.
6. 앰프 연결(둘 중 하나)
   - 블루투스: 앰프 SELECT를 USB로 → 앰프 [MODE] 버튼을 눌러 화면에 bLUE가 뜨게 → 폰 설정 → [연결] → [블루투스] → 앰프 이름을 눌러 연결. 지금 음악을 트는 폰이 연결되어 있으면 그 폰의 블루투스를 먼저 끈다.
   - 선: 3.5mm to RCA 케이블로 앰프 뒷면 [AUX1]에 연결 → 앰프 SELECT를 AUX1로. 이때 블루투스 음악은 안 나오므로, 음악은 방송 폰에서 튼다.
7. 소리 확인: 앱의 [테스트 방송] → 앰프 [MUSIC] 노브와 앱의 방송 음량으로 크기를 맞춘다.
8. 앱 화면에 보이는 주소(예: 192.168.0.23:8080)를 적어 두고, 충전기를 꽂아 둔다.

### 5-2. 매장 태블릿(매장마다, 손님 없는 시간에)

1. 앱 설치: Chrome에서 고정 주소 열기 → [다운로드] → [열기] → [설정] → [이 출처 허용] 켜기 → 뒤로 → [설치]. 경고가 뜨면 5-1의 3번과 같이 처리한다.
2. 연결: 앱 실행 → [매장용] → 매장 고르기 → [자동 찾기] → [연결 테스트]. 자동 찾기가 안 되면 방송 폰 주소를 직접 넣는다.
3. 접근성 켜기: 앱의 [접근성 설정 열기] → [설치된 앱] → [호출 방송] → 켜기 → [허용]. "제한된 설정" 안내가 뜨면 [확인]을 누르고 4번으로 간다.
4. 제한된 설정 풀기(안드로이드 13 이상): 설정 → [애플리케이션] → [호출 방송] → 오른쪽 위 ⋮ → [제한된 설정 허용] → 화면 잠금 해제 → 다시 3번.
5. 배터리: 앱의 [배터리 제한 없음으로] → [허용].
6. 확인: 키패드로 - 2 4 Enter → 방송이 나온다. 2 4 Enter → 호출 화면에 평소대로 뜬다.
7. 호출 앱 화면으로 돌려놓는다.

안드로이드 12 이하는 4번 없이 3번에서 바로 켜진다.

### 5-3. 끄기·삭제·업데이트

- 바로 끄기: 설정 → [접근성] → [설치된 앱] → [호출 방송] → 끄기. 키패드가 즉시 원래대로 동작한다.
- 삭제: 설정 → [애플리케이션] → [호출 방송] → [삭제].
- 업데이트: 고정 주소에서 다시 받아 [설치]하면 덮어쓰고, 설정은 그대로 남는다.

## 직원 휴대폰 예비 입구

태블릿이나 키패드가 고장 나면, 같은 와이파이에 붙은 아무 휴대폰 브라우저에서
`http://<방송 폰 주소>:8080/s/하즈벤` 처럼 매장 이름을 붙여 열면 큰 숫자 버튼 화면이 나옵니다.
`http://<방송 폰 주소>:8080/` 은 상태 페이지(대기열, TTS 상태, 최근 방송 20건, 매장별 링크)입니다.

방송 폰에 토큰을 설정했다면 `…/s/하즈벤?t=토큰` 으로 엽니다.

## 설정 화면 요약

**매장용**: 매장 선택(방송 폰의 목록을 받아 올 수 있음), 방송 장치 주소·[자동 찾기]·[연결 테스트], 접근성 상태, 배터리,
방송 키(키패드 `-`, 일반 `-`, `*`, `/`, `+`, `.` 중 선택), 자동 취소 시간, "이동 키를 숫자로 해석",
[키 입력 확인](마지막 10개 키의 키 코드 이름), [테스트 방송], 최근 전송 5건.

**방송용**: 이 폰 주소(크게), 서버 상태·[서버 다시 시작], TTS 상태·[TTS 설정 열기], [테스트 방송],
방송 음량(0~100, 시스템 음량은 안 바꿈), 말하기 속도, 반복 횟수(1~3), 차임 켜기/끄기, 앞 무음(ms), 중복 무시 시간(초),
포트·토큰, 매장 목록 편집(읽는 이름, 문장, 사용 여부), 최근 방송 20건, 배터리.

## 동작 요약

| 항목 | 값 |
|---|---|
| 전송 | `POST /call`, 연결 제한 3초, 실패 시 1초·2초 뒤 재시도 → 그래도 실패하면 NSD로 방송 폰을 다시 찾아 한 번 더 |
| 태블릿 쪽 중복 | 같은 번호를 3초 안에 다시 보내면 한 번만 |
| 방송 폰 쪽 중복 | 같은 매장·같은 번호가 20초(설정) 안에 다시 오면 방송 안 함(`duplicate: true`) |
| 대기열 | 한 건씩 차례로 방송, 30건 넘으면 가장 오래된 건 버림(기록 남김) |
| 소리 | [앞 무음 500ms] → [딩동] → [문장] × 반복(사이 0.8초). 재생 중 음악은 작아졌다가 돌아옴 |
| 번호 읽기 | 앞의 0을 뗌("024" → "24번"), 모두 0이면 "0번" |
| 자동 시작 | 앱 실행, 부팅 완료, 앱 업데이트 뒤 |
| 기록 | 앱 내부 파일(JSON Lines), 7일 지나면 삭제 |

## 통신 규약(4-4)

문자 인코딩은 UTF-8. 매장 이름은 앞뒤 공백을 무시하고 비교한다. 2단계 PC 서버도 이 규약을 그대로 따르면 매장용 앱을 바꾸지 않아도 된다.

```
POST /call
  헤더  Content-Type: application/json
        X-Token: (방송용 설정에 토큰이 있을 때만 확인, 기본은 비어 있음)
  본문  {"store":"하즈벤","number":"24","source":"keypad","device":"하즈벤 태블릿","test":false}
        source: keypad(매장 태블릿) / web(직원 휴대폰) / app(설정 화면 테스트)
        test가 true면 number는 없어도 되고, "방송 테스트입니다. {매장}"을 읽는다.

  응답 200  {"ok":true,"queued":true,"duplicate":false,"position":1}
  응답 200  {"ok":true,"queued":false,"duplicate":true}
  응답 400  {"ok":false,"error":"invalid_number"}   숫자 1~5자리가 아님
  응답 404  {"ok":false,"error":"unknown_store"}    목록에 없거나 사용 안 하는 매장
  응답 401  {"ok":false,"error":"bad_token"}

GET /status        {"ok":true,"version":"1.0.12","uptimeSec":3600,"queue":0,"tts":"ready","ip":"192.168.0.23","port":8080}
GET /stores        {"stores":[{"name":"하즈벤","enabled":true}, ...]}
GET /log?limit=50  최근 방송 기록(JSON). &store=하즈벤 으로 매장만 볼 수 있음
GET /              상태 페이지(HTML)
GET /s/{매장}       직원 휴대폰용 페이지(HTML)
```

PC에서 시험할 때:

```bash
curl -X POST http://192.168.0.23:8080/call -H 'Content-Type: application/json' \
  -d '{"store":"하즈벤","number":"24","source":"app","device":"PC","test":false}'
```

## 현장 확인 필요

코드로 확인할 수 없어 현장 기기에서 꼭 확인해야 하는 것들입니다.

- **제조사별 접근성 동작**: 일부 제조사(특히 저가 태블릿·업체 전용 펌웨어)는 접근성 서비스의 키 필터(`flagRequestFilterKeyEvents`)를 막거나, 절전 때문에 서비스를 꺼 버릴 수 있습니다. [키 입력 확인]에 키가 찍히는지, 재부팅 뒤에도 "켜짐 · 동작 중"인지 확인합니다.
- **앱이 여러 번 멈추면** 안드로이드가 접근성 서비스를 스스로 끌 수 있습니다. 방송이 안 되면 먼저 접근성 화면에서 켜져 있는지 봅니다.
- **키패드 키 코드**: COSY 키패드의 `-`가 `KEYCODE_NUMPAD_SUBTRACT`인지 `KEYCODE_MINUS`인지, `Enter`가 `KEYCODE_NUMPAD_ENTER`인지 [키 입력 확인]으로 봅니다. 다른 코드가 오면 방송 키 설정을 바꿉니다.
- **Num Lock**: Num Lock이 꺼진 상태에서 숫자 대신 `MOVE_END`, `DPAD_DOWN` 같은 이동 키가 찍히면 "이동 키를 숫자로 해석"을 켭니다. 이때 숫자 `5`가 어떤 키로 오는지는 키패드마다 다르며 현재 해석 목록에는 없습니다.
- **기존 호출 앱이 `-` 키를 쓰는지**: 쓰면 방송 키를 `*` 등으로 바꿉니다.
- **블루투스 지연**: 블루투스 앰프는 재생 시작 때 앞부분이 잘릴 수 있습니다. 차임 앞부분이 잘리면 앞 무음을 800~1500ms로 늘립니다.
- **C타입 오디오 젠더**: 충전 겸용 젠더는 폰마다 호환이 다릅니다. 충전하면서 소리가 나오는지 확인합니다.
- **층간 통신**: 1층 태블릿에서 2층 방송 폰으로 통신되는지(공유기가 층별로 따로 있음). 매장용 앱의 [연결 테스트]로 확인합니다. 안 되면 2단계 PC 서버로 갑니다.
- **NSD 자동 찾기**: 공유기 설정(멀티캐스트 차단, AP 격리)에 따라 [자동 찾기]가 안 될 수 있습니다. 그때는 주소를 직접 넣습니다. 방송 폰 주소가 바뀌지 않게 공유기에서 **고정 IP(DHCP 예약)** 를 걸어 두는 것을 권합니다.
- **TTS 엔진**: 삼성 TTS와 구글 TTS의 한국어 음성이 깔려 있어야 합니다. 일부 엔진은 WAV 파일 만들기를 지원하지 않는데, 이때 앱은 차임을 먼저 울리고 TTS로 바로 읽는 방식으로 대신합니다(이 경우 음량·반복은 같지만 앞 무음과 차임이 별도 재생됨).
- **음악 덕킹**: 같은 폰에서 트는 음악은 방송 중 작아집니다(지금 운영 방식). 다른 기기에서 트는 음악은 줄어들지 않습니다. 일부 음악 앱은 작아지는 대신 잠깐 멈췄다가 다시 재생하는데, 현장에서 쓰는 음악 앱으로 확인합니다.
- **음악 폰 음량**: 폰의 음량 버튼은 음악과 방송을 함께 바꿉니다. 방송만 키우려면 앱의 방송 음량을 씁니다(최대 100). 음악을 아주 크게 틀어 두면 방송이 상대적으로 작게 들릴 수 있습니다.
- **방송 전용 키패드(선택 기능)**: 아직 만들지 않았습니다. 기본 기능이 현장 완료 기준을 통과하면 추가합니다. 같은 모델 키패드 두 개는 입력 장치 식별값이 같아 구분되지 않을 수 있으므로, 방송 전용 키패드는 **다른 모델**을 씁니다.
- **앱 안 업데이트(선택 기능)**: 아직 만들지 않았습니다. 지금은 고정 주소에서 다시 받아 설치합니다.

## 현장 확인 후 정할 것(지시서 6장)

| 확인할 것 | 결과에 따라 정할 것 |
|---|---|
| 태블릿 모델과 안드로이드 버전, 설정 화면에 들어갈 수 있는지 | 설정이 잠겨 있으면 이 방식은 안 된다. 매장별 방송 전용 키패드 + 소형 보드(라즈베리파이 제로 2 W)로 바꾼다 |
| 태블릿 소유(매장·운영사 / 호출 업체)와 앱 설치 허락 | 호출 업체 소유면 업체·운영사 허락을 먼저 받는다 |
| 매장 태블릿이 붙은 와이파이와 IP, 1층 태블릿에서 2층 방송 폰으로 통신되는지 | 안 되면 2단계 PC 서버(유선·무선 동시 연결)로 간다 |
| 기존 호출 앱이 키패드의 - 키를 쓰는지 | 쓰면 방송 키를 * 등으로 바꾼다 |
| 방송 방식: (가) - + 번호 / (나) 방송 전용 키패드 | (나)면 선택 기능을 켜고 키패드를 추가로 산다 |
| 컴포즈 포함 여부 | 포함하면 방송용 매장 목록에서 켠다 |
| 음악을 어떤 기기로 트는지 | 방송 폰으로 합칠지, 블루투스와 선 중 어느 쪽으로 연결할지 |
