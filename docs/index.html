앰프 연결 확인

음악 트는 폰이 이미 블루투스로 붙어 있으므로 보통은 할 일이 없습니다. 아래 A로 확인만 하세요.

A. 지금 그대로 (블루투스)

추천 · 바꿀 것 없음
  1. 앰프 화면에 bLUE가 떠 있는지
  2. 폰 블루투스 목록에서 앰프가 연결됨인지
  3. 음악이 스피커로 잘 나오면 끝
연결이 끊겨 있으면: SELECT를 USB로 → MODE를 눌러 bLUE → 폰 설정 → 연결 → 블루투스 → 앰프 이름.

B. 선 연결

블루투스가 자주 끊길 때만 · 3.5mm to RCA 케이블
  1. 케이블로 폰과 앰프 뒷면 AUX1 연결
  2. 앰프 SELECT를 AUX1로
  3. 음악도 방송도 같은 폰에서 그대로
이어폰 구멍이 없는 폰은 충전 겸용 C타입 오디오 젠더가 필요합니다.

안 될 때

위에서부터 차례로 확인하세요.

방송 장치에 연결 안 됨
  1. 태블릿 위쪽에 와이파이 표시가 있는지
  2. 2층 방송 폰이 켜져 있고 충전 중인지
  3. 급하면 휴대폰으로 방송 또는 무선 마이크
−를 눌러도 아무 표시가 안 뜸
  1. 앱을 열어 접근성 서비스가 초록 "켜짐 · 동작 중"인지
  2. 꺼져 있으면 태블릿 설치 3번을 다시
초록 "요청 완료"인데 소리가 안 남
  1. 앰프 전원과 SELECT(USB 또는 AUX1), MUSIC 노브
  2. 블루투스면 방송 폰이 앰프에 연결돼 있는지
  3. 방송 폰 앱의 테스트 방송과 방송 음량
방송할 때 음악이 멈췄다가 다시 나옴
  1. 일부 음악 앱은 작아지는 대신 잠깐 멈춥니다. 방송이 끝나면 다시 나오므로 그대로 써도 됩니다.
  2. 음악이 다시 안 나오면 음악 앱에서 재생을 한 번 눌러 주세요.
음악은 나오는데 방송만 안 나옴
  1. 음악 폰이 2층 와이파이에 붙어 있는지 (모바일 데이터만 켜져 있으면 안 됨)
  2. 폰 위쪽 알림에 "방송 대기 중"이 있는지. 없으면 호출 방송 앱을 한 번 열기
  3. 누가 폰을 가져가지 않았는지
"딩동" 앞부분이 잘려서 들림
  1. 방송 폰 앱 → 소리 → 앞 무음을 500에서 1000으로 늘리고 저장

키패드가 이상할 때 바로 끄기

태블릿 설정→접근성→설치된 앱→호출 방송→끄기
끄는 즉시 키패드가 원래대로 호출 화면에만 동작합니다. 기존 호출 시스템에는 아무 영향이 없습니다.
