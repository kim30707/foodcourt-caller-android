앰프에 연결

태블릿은 선 연결(A)을 권합니다. 블루투스보다 끊김이 없습니다.

A. 선 연결

추천 · 3.5mm to RCA 케이블
  1. 태블릿 이어폰 단자와 앰프 뒷면 AUX1을 케이블로 연결
  2. 앰프 앞면 SELECT를 AUX1로
  3. 태블릿 블루투스는 꺼 두기 (소리가 블루투스로 새지 않게)

B. 블루투스

케이블을 못 쓸 때만
  1. 앰프 SELECT를 USB로 → MODE를 눌러 bLUE
  2. 태블릿 설정 → 블루투스 → 앰프 이름 연결

  2. 2층 방송 태블릿이 켜져 있고 충전 중인지
  3. 방송 태블릿 주소가 바뀌었으면 1~2분 기다리면 스스로 다시 붙습니다. 급하면 앱의 [방송 장치 찾기·연결 확인]
  4. 설정 화면에 "연결 끊음"이 보이면 누가 [연결 끊기]를 누른 것입니다. [방송 장치 찾기·연결 확인]
  5. 급하면 휴대폰으로 방송 또는 무선 마이크
−를 눌러도 아무 표시가 안 뜸
  1. 앱을 열어 설정 3. 키패드 기능이 초록 ✔인지
  2. 꺼져 있으면 매장 태블릿 설치 4번을 다시
  3. [키패드 눌러 보기]에 키 이름이 안 나오면 키패드 선(USB)을 다시 꽂기
초록 "요청 완료"인데 소리가 안 남
  1. 앰프 전원과 SELECT(AUX1 또는 USB), MUSIC 노브
  2. 방송 태블릿 앱의 음성(TTS)이 "준비됨"인지. 아니면 방송 태블릿 설치 3번
  3. 방송 태블릿 앱의 테스트 방송과 방송 음량
음악이 시간에 맞춰 켜지거나 꺼지지 않음
  1. 앱 음악 자동 켜기/끄기의 사용이 켜져 있고, 시각이 저장됐는지
  2. 유튜브 뮤직 프리미엄인지, 재생목록을 한 번 틀어 두었는지
  3. [지금 켜기 테스트]를 눌러 아래 결과 문장을 확인
방송할 때 음악이 멈췄다가 다시 나옴
  1. 일부 음악 앱은 작아지는 대신 잠깐 멈춥니다. 방송이 끝나면 다시 나오므로 그대로 써도 됩니다.
  2. 음악이 다시 안 나오면 음악 앱에서 재생을 한 번 눌러 주세요.
"딩동" 앞부분이 잘려서 들림
  1. 방송 태블릿 앱 → 소리 → 앞 무음을 500에서 1000으로 늘리고 저장

키패드가 이상할 때 바로 끄기

매장 태블릿 설정→접근성→설치된 앱→호출 방송→끄기
끄는 즉시 키패드가 원래대로 호출 화면에만 동작합니다. 기존 호출 시스템에는 아무 영향이 없습니다.
